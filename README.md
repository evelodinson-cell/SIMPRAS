# SIMPRAS — Tahap 2 Tanpa Supabase

Versi ringan untuk GitHub Pages. Tidak membutuhkan Supabase/database cloud.
Data demo disimpan di browser menggunakan localStorage.

Akun:
- admin / adminsarpras
- osis / osis123
- pramuka / pramuka123
- pmr / pmr123

Fitur:
- Login multi-role
- Dashboard Admin/Peminjam
- Sarana dan Prasarana
- Tambah/edit/hapus aset oleh Admin
- Status aset
- Pengajuan peminjaman
- Pencegahan bentrok jadwal
- Persetujuan/penolakan
- Jadwal
- Notifikasi
- Riwayat aktivitas
- Laporan sederhana

Catatan: karena GitHub Pages adalah hosting statis, data tersimpan di browser/perangkat yang digunakan. Cocok untuk demo/presentasi. Untuk sinkronisasi real-time antar banyak perangkat diperlukan backend/database.
