# SIMPRAS
Sistem Informasi Manajemen Sarana dan Prasarana.

## Tahap 1
Fondasi halaman login SIMPRAS.

## Tahap berikutnya
1. Hubungkan Supabase.
2. Buat tabel dan relasi database.
3. Buat autentikasi Admin Sarpras dan Peminjam.
4. Buat dashboard berdasarkan role.
5. Buat data Sarana dan Prasarana.
6. Tambahkan pengajuan, jadwal, notifikasi, laporan, dan riwayat aktivitas.

> Password akun tidak disimpan di JavaScript frontend. Autentikasi akan ditangani oleh backend/auth setelah Supabase dikonfigurasi.
